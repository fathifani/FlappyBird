# Flappy Bird

A single-file Java Swing mini project that recreates the Flappy Bird game. The project uses object-oriented programming concepts including inheritance, encapsulation, polymorphism, and abstraction. Press SPACE to flap and restart the game.

## Features

- Simple Flappy Bird-style gameplay
- Built with Java Swing
- Single source file: `FlappyBird.java`
- Uses inheritance, encapsulation, polymorphism, and abstraction

## Requirements

- JDK 8 or later

## Setup and Run

1. Place `FlappyBird.java` in a folder.
2. Open a terminal in that folder.
3. Compile the game:

   ```bash
   javac FlappyBird.java
   ```

4. Run the game:

   ```bash
   java FlappyBird
   ```

## Controls

- **SPACE**: Flap
- **SPACE**: Restart after a game over
